# Virtual Canvas using Hand Gestures

A real-time virtual drawing application developed using Python, OpenCV, and MediaPipe. The project allows users to draw in the air using hand gestures detected through webcam input.

## Features

* Hand Tracking
* Air Drawing
* Gesture Recognition
* Eraser Mode
* Real-time Webcam Interaction

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy
